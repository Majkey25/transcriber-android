Privacy policy

Transcriber, Android package cz.majkey.prepis, is published by Matěj Teplý, developer name Majkey. Contact: majkeylab@gmail.com.

The app has no developer account, advertising, analytics SDK or developer-operated transcription server. It reads M4A files only from a folder you select using the Android picker. It does not request microphone, contacts or location access.

The explicit cloud-consent controls below require version 0.3.1 or later. Older versions can automatically upload recordings when a cloud model and API key are configured. Update before using cloud transcription, or select Local Smart and remove API keys to keep processing local.

  • Local Smart: audio is decoded and transcribed on the phone. Initial model downloads contact Hugging Face, which receives the IP address and normal download request information, not your recordings. Downloaded files are verified with SHA-256. After download, local transcription works offline.
  • Optional cloud models: after you confirm automatic uploads, existing recordings missing a transcript and new recordings in the selected folder are sent to the selected provider, including in background jobs. A separate cloud transcription action sends the selected recording. Audio, a sanitized filename, the selected language/model and your API credential are sent over HTTPS directly to OpenAI, Google Gemini, Groq or xAI. No developer backend receives them.
  • Local storage: transcripts, model files, folder access, selected settings and upload consent remain in app-private storage. API keys are encrypted using Android Keystore. App data is excluded from Android backup. Copied transcript text enters the Android clipboard and may be accessible to the app you paste into.

Cloud processing, retention, international transfers, possible service improvement use and charges depend on the provider and your account terms. Read them before uploading sensitive recordings: OpenAI, Gemini API, Groq, xAI. The app attempts to delete its temporary Gemini uploaded file after processing; this does not override provider logs, other retention rules or a failed deletion request. Hugging Face privacy.

Only record or upload people whose audio you are entitled to process and share. The app is a general-purpose tool, not a service directed at children. It does not ask for age or create child profiles. A provider may impose its own age requirements.

Retention, withdrawal and deletion

Choose Local Smart in Settings or remove an API key to withdraw cloud upload permission and cancel queued cloud jobs. A transfer already in progress may finish; data already sent cannot be recalled. On upgrade, old cloud settings do not authorize uploads until you confirm again.

To delete all app-held transcripts, encrypted keys, models and settings, use Android Settings → Apps → Transcriber → Storage → Clear storage, or uninstall. Your original recordings remain in the folder you selected; delete those separately with your file manager or recorder. Copies you pasted elsewhere must be deleted there. There is no Transcriber account to delete.

For data already sent to a cloud provider, use that provider's account/privacy controls. The developer cannot remotely read or erase your phone or provider account. For support correspondence or a privacy request, email majkeylab@gmail.com. Include only what is needed; do not send recordings or API keys.

A support email shares your address and message with the developer and email provider to handle your request. The basis is the legitimate interest in answering support requests, or a legal obligation when handling statutory requests. Correspondence is retained only while needed to resolve the request, a related dispute or a legal duty. You can request access, correction, deletion, restriction, portability or object to processing where applicable, and complain to a data protection authority, such as the Czech Office for Personal Data Protection.

Terms and costs

The developer provides this app without an app purchase, subscription or in-app billing. Cloud API providers can charge your own API account or apply quotas. Review their current prices before enabling uploads. Refund requests for provider charges belong with that provider; statutory consumer rights are unaffected.

Transcripts can be inaccurate. Check important results against the recording. Use the app lawfully and respect other people's privacy and copyrights.
